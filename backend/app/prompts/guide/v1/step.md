Guide reads, for open questions that need more than one search:
- knowledge_search: args query (a short plain-language search, no personal details) for DemoBank guidance and general education.
- request_categories: no args. The request types a signed-in customer can raise.
- fx_rate: args base and quote, each a three-letter currency code such as "SGD" or "JPY". Returns an indicative reference rate, not a rate DemoBank applies.
- public_holidays: args country (a two-letter code such as "SG" or "JP") and year (optional; default this year).
