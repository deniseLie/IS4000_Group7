# SQL for the hosted Supabase project

`../migrations/` is the source of truth and runs automatically in local tests. These files are for the **hosted** project only and are pasted into the Supabase SQL editor by hand, in order. Each `NN_apply_*` file is generated by `python -m scripts.prepare_hosted_migrations --first N --last M --output ...` and is safe to re-run: migrations already recorded are skipped.

After applying, restart the backend. `DOCUMENT_PRECHECK_SIGNING_KEY` in `backend/.env` must equal `select secret from compliance.precheck_keys where key_id='v1';`.
