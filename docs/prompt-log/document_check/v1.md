# document_check v1

Notice-grounded layout interpretation for synthetic document prechecks. Input contains the owned recorded notice/item instructions and bounded extracted document text, request-local only. Output quotes are checked against the original sources; only bounded finding codes and field enums are retained. Calendar freshness, period coverage, explicit page counts and minimum coverage are independently checked. Unsupported, ambiguous or ungrounded results cannot pass. Model semantics are not authenticity, identity or signature verification. Provider failures remain explicit.

Validation: unit adversarial/quotation/calendar checks, real-provider API/browser tests and Computer Use are recorded in the workflow document.
