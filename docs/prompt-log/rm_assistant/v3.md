## rm_assistant v3

Clarifies book-wide schedule questions: list the recorded confirmed meetings for follow-up priorities and identify clients without one, while distinguishing held and past appointments. Future follow-up options use only upcoming confirmed appointments. Single-meeting ambiguity still requires clarification. Other task files retain v2 behaviour. Used by `services/rm/assistant.py`; validation is the real R19 conversation and native RM boundaries. Tone-only message revisions preserve the current draft’s subject and facts; chat never sends a revision. Inbox triage includes the recorded urgency, owner, age and overdue flag for each owned ticket.
