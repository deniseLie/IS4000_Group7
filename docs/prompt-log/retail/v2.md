| Hypothesis | Explicit dataset boundaries should reduce invented personal facts and currency inference; conservative figure checks may withhold valid answers. |
| Eval run | Full backend: 575 passed, 44 opt-in skips. Final focused retail/prompt checks: 11 passed, 2 live skips. Three actual-provider account cases, one actual-provider missing-loan-currency case, real-provider saved-chat browser integration at 1280/768/390/320 pixels, and Computer Use against hosted Supabase. No comparative accuracy dataset measured. |
| Results | All three persona account amounts retained SGD and the owned account citation. The loan-currency case explicitly reported missing currency without borrowing SGD. The normal UI retained the real answer and sources after saved-chat reload. Computer Use verified David's hosted SGD 84,120 answer and reload; it also included a supplied public account source. Native readers cover empty collections, customer boundaries and permission/read failures. Invalid figures, currencies, datasets and action claims are withheld; missing provider configuration withholds the answer. The orchestrator’s separate support handoff is documented in README. |
| Failures observed | The first browser question invoked a slow planner and exceeded the test timeout; the browser harness also could not read the completed SSE body. The final single-question test asserts the rendered answer and persisted state instead. One loan-currency provider call timed out after its configured retry; a subsequent real call passed. An ambient audit batch leaked between direct service tests; the new retail tests now isolate their context. These failures are not counted as accuracy passes. |
| Decision | Release personal retail v2 behind `PIPELINE=v2`; preserve public retail v1 and the default v1 pipeline. Broader retail and multilingual semantic evaluation remains open. |
| Known limits | Numeric/citation checks do not prove semantic grounding, correct classification or correct subject attribution. Snapshots are separate reads, collection bounds apply, and model/provider failures must remain explicit. |
