| Field | Value |
|---|---|
| Prompt name / files | `talking_points/v1/system.md` |
| Version ID (`v<N>+hash`) / git commit | `v1+254803bd`, pinned in `tests/test_prompts.py` |
| Author / reviewer | Group 7 |
| Goal | Lane 1 of the talking-point pipeline (RM copilot build plan phase 4, migration 0108): classify one client message into list values (topic, stage, timeframe, concerns) plus her exact quote, for her RM's meeting preparation |
| Model + provider | `TALKING_POINTS_MODEL` when set, else `LLM_MODEL`, through `llm_gateway.call` (API transport). Live run: `anthropic/claude-haiku-5.5` on OpenRouter |
| Parameters | Provider default temperature; `max_tokens` from settings and the request budget; strict JSON schema `talking_points` (`points[]` with enums for topic, stage, timeframe and concerns, plus `quote`); `retries=0` |
| Context fed in | Her redacted latest message and her redacted previous message, as JSON data. Never the assistant's reply, records or other people's text |
| Change from previous | First version |
| Hypothesis | Few false topics, because code keeps a point only when the quote is her exact words, holds a word from the topic's list, the topic is not muted and no sensitive word matches. Expected regressions: recall loss when her quote leaves out the topic word |
| Eval run | `python -m evaluation.talking_points --live`, `evaluation/talking_points_cases.json`, `dataset_sha256` `732300cfa6eaa28bf99db1110c2276f37170c29c09afa43fdeec56cd8aaed2c3`, 61 cases, 5 Nov 2026 (one live run) |
| Results | 38 model calls (23 cases were stopped by care or the pre-filter first). Micro precision 1.000, recall 0.969 (31 of 32 labelled topics). Per topic precision/recall: home_loan 1.000/0.909, investments 1.000/1.000, fixed_deposit 1.000/1.000, insurance 1.000/1.000. Stage agreed on 28 of 31 found topics (0.903). Negative, sensitive, care and injection groups: 31 of 31 cases recorded nothing they should not have. Lane 2 rule: 8 offers, no false prompts |
| Failures observed | TP04 ("We've found an HDB flat and want to apply for the loan now"): the quote the model chose had no word from the home-loan list, so the validator dropped it. Stage differences: TP01 curious instead of planning, TP02 exploring instead of curious, TP27 insurance ready instead of planning |
| Decision | Adopted with phase 4 |
| Known limits | One sample from a non-deterministic model on 61 synthetic English messages; not tested on other languages, long conversations or real client wording. The first live attempt failed locally on every call before any request was sent: the schema had no `title`, which LangChain's strict structured output needs. It was fixed and is now covered by a unit test |
